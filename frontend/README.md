# 智慧医疗管理系统前端

基于 Vue 3、TypeScript、Vite、Pinia 与 Element Plus 的三角色医疗业务前端。

当前前端已经从旧医院系统的通用模型工作区中独立出来，只保留毕业设计的核心范围：

- 管理员：账户、科室、医师、患者、排班、预约、检查、统计与审计。
- 医师：个人排班、接诊、患者、病历、处方与检查。
- 患者：医师查询、预约挂号、个人病历、个人处方与检查报告。
- 智慧医疗：保留服务中心与后续 AI 分析任务入口。

## 本地运行

```bash
npm install
npm run dev
```

默认将 `/api` 代理到 `http://127.0.0.1:8000`。新后端接口前缀为 `/api/v1/`，可以通过环境变量覆盖：

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1/
```

生产构建：

```bash
npm run build
```

详细阶段与验收条件见 [重构路线](docs/REFACTOR_ROADMAP.md)。

> 本项目为教学演示系统，不应录入未经授权的真实患者数据，也不能直接用于临床诊疗。
