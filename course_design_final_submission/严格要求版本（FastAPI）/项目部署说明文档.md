# 慧医云智能医疗预约系统——项目部署说明

## 1. 项目说明

本项目为课程设计提交版，包含用户认证、科室管理、医师信息、医师排班、号源预约、预约状态流转和数据看板等功能。

- 后端：FastAPI、SQLAlchemy 2、PyMySQL、PyJWT、Uvicorn
- 前端：Vue 3、Vite、TypeScript、Element Plus、Axios、ECharts
- 数据库：MySQL 8.0
- 接口分层：Controller（接口与参数）→ Service（业务规则）→ Mapper（数据库查询）

交付文件如下：

```text
├─ backend.zip                  后端源码
├─ frontend.zip                 前端源码及生产构建 dist
├─ smart_medical.sql            建表与初始化测试数据
└─ 项目部署说明文档.md
```

## 2. 环境要求

建议使用以下版本：

- Python 3.10 或更高版本
- MySQL 8.0
- Node.js 18 或更高版本
- npm 9 或更高版本

## 3. 初始化数据库

`smart_medical.sql` 会删除并重新创建名为 `smart_medical` 的数据库，请勿在已有正式数据库上直接执行。

在 Windows 或已允许 root 密码登录的 MySQL 环境中执行：

```bash
mysql -u root -p < smart_medical.sql
```

输入 MySQL root 密码后，脚本会自动完成建库、建表、索引、外键和演示数据初始化。

Ubuntu/Debian 默认可能使用系统账户认证。如果出现 `ERROR 1698 (28000): Access denied for user 'root'@'localhost'`，请在交付目录执行：

```bash
sudo mysql < smart_medical.sql
```

然后为本项目创建独立的数据库账号：

```bash
sudo mysql
```

进入 MySQL 后逐条执行：

```sql
CREATE USER IF NOT EXISTS 'medical_user'@'localhost' IDENTIFIED BY 'Medical123!';
GRANT ALL PRIVILEGES ON smart_medical.* TO 'medical_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

可以使用以下命令验证账号和数据库：

```bash
mysql -u medical_user -p -e "USE smart_medical; SHOW TABLES;"
```

也可以使用 Navicat、DataGrip 或 MySQL Workbench 打开 `smart_medical.sql` 并执行全部语句。

## 4. 启动后端

解压 `backend.zip`，进入解压后的 `backend` 目录。

### 4.1 创建虚拟环境

使用 venv：

```bash
python -m venv .venv
```

Windows 激活命令：

```bash
.venv\Scripts\activate
```

Linux/macOS 激活命令：

```bash
source .venv/bin/activate
```

也可以使用 Conda：

```bash
conda create -n smart-medical python=3.11 -y
conda activate smart-medical
```

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 配置环境变量

复制配置模板：

Windows：

```bash
copy .env.example .env
```

Linux/macOS：

```bash
cp .env.example .env
```

编辑 `.env`，将数据库用户名、密码和地址改为本机配置：

```env
APP_NAME=慧医云智能医疗系统
DATABASE_URL=mysql+pymysql://medical_user:Medical123%21@127.0.0.1:3306/smart_medical?charset=utf8mb4
JWT_SECRET=请改为一段较长的随机字符串
ACCESS_TOKEN_MINUTES=120
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

如果密码包含 `@`、`#`、`/` 等特殊字符，需要先进行 URL 编码。

### 4.4 启动接口服务

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

启动后可访问：

- 健康检查：`http://127.0.0.1:8000/api/v1/health`
- Swagger 接口文档：`http://127.0.0.1:8000/docs`

### 4.5 运行后端测试

测试使用临时 SQLite 数据库，不会修改 MySQL 演示数据：

```bash
python -m pytest -q
```

## 5. 启动前端

解压 `frontend.zip`，进入解压后的 `frontend` 目录。

安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。Vite 已将 `/api` 请求代理到 `http://127.0.0.1:8000`，因此应先启动后端。

生成生产版本：

```bash
npm run build
```

构建结果位于 `dist` 目录。提交包内已包含一次通过校验的 `dist`。本地预览命令：

```bash
npm run preview
```

## 7. 主要源码结构

后端：

```text
backend/
├─ app/
│  ├─ controllers/    Controller：路由、参数和权限入口
│  ├─ services/       Service：排班、预约和状态流转规则
│  ├─ mappers/        Mapper：SQLAlchemy 查询与持久化
│  ├─ models/         ORM 数据模型
│  ├─ schemas/        Pydantic 请求与响应模型
│  ├─ core/           配置、数据库、JWT 和依赖注入
│  └─ main.py         FastAPI 应用入口
├─ tests/             核心接口测试
└─ requirements.txt
```

前端：

```text
frontend/
├─ src/
│  ├─ api/            Axios 封装与统一错误提示
│  ├─ router/         页面路由与登录拦截
│  ├─ stores/         Pinia 登录状态
│  ├─ views/          中文业务页面
│  └─ style.css       全局样式
├─ dist/              生产构建结果
└─ package.json
```

## 8. 常见问题

1. **后端提示无法连接 MySQL**：检查 MySQL 服务是否启动，以及 `.env` 中的用户名、密码、端口和数据库名。
2. **前端提示网络错误**：确认后端运行在 8000 端口，并通过健康检查地址验证接口。
3. **登录提示账号或密码错误**：重新执行 `smart_medical.sql`，确认初始化数据已写入当前连接的数据库。
4. **端口被占用**：修改 Uvicorn 的 `--port` 后，还需同步修改 `vite.config.ts` 中的代理地址。
