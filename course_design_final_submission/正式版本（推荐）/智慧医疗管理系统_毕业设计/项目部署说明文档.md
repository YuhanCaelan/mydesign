# 智慧医疗管理系统部署说明

## 1. 技术栈

- 后端：Python、Django、Django REST Framework、Simple JWT
- 前端：Vue 3、TypeScript、Vite、Pinia、Element Plus、Axios、ECharts
- 数据库：SQLite
- 接口地址：`/api/v1/`

正式版使用 SQLite，便于课程答辩时快速部署和迁移。`smartmedical_sqlite.sql` 同时包含数据表结构和固定的虚构测试数据。

## 2. 环境要求

- Python 3.10 或更高版本
- Node.js 18 或更高版本（仅重新开发或构建前端时需要）
- SQLite 3
- 推荐使用项目开发环境：Conda `hos`
- 在线演示：https://smarthospital.cc.cd/

## 3. 解压文件

将本目录中的 `backend.zip` 解压到当前目录。解压后结构如下：

```text
正式版本（推荐）/
├─ backend/
│  ├─ healthcare/
│  ├─ smartmedical/
│  ├─ frontend/dist/       已构建的前端页面
│  ├─ manage.py
│  └─ requirements.txt
├─ smartmedical_sqlite.sql
└─ 项目部署说明文档.md
```

`frontend.zip` 是完整前端源码，用于查看或继续开发。运行系统时，`backend.zip` 已经包含最新的 `frontend/dist`，无需再次执行前端构建。

## 4. 安装后端依赖

进入后端目录：

```bash
cd backend
```

使用现有 Conda 环境：

```bash
conda activate hos
pip install -r requirements.txt
```

也可以新建环境：

```bash
conda create -n smartmedical-full python=3.11 -y
conda activate smartmedical-full
pip install -r requirements.txt
```

## 5. 初始化数据库

### 方法一：导入提交的完整演示数据

确保当前位于 `backend` 目录，并且原来不存在 `smartmedical.sqlite3`：

```bash
sqlite3 smartmedical.sqlite3 < ../smartmedical_sqlite.sql
```

该脚本包含 10 个科室、6 名医师、12 名患者、96 条预约、66 份病历、38 张处方、40 项检查、8 次住院及相关费用和审计数据。

### 方法二：使用 Django 命令重新生成

```bash
python manage.py migrate
python manage.py seed_smartmedical
```

需要清空本地数据库并重建固定演示数据时执行：

```bash
python manage.py seed_smartmedical --reset
```

`--reset` 会清空当前数据，只能用于课程演示环境。

## 6. 启动系统

```bash
python manage.py runserver 127.0.0.1:8000
```

浏览器访问：

```text
http://127.0.0.1:8000/app/
```

## 8. 前端开发与重新构建

将 `frontend.zip` 解压到任意开发目录后执行：

```bash
npm ci
npm run dev
```

开发服务器默认访问 `http://127.0.0.1:5173`，并将 `/api` 代理到 Django 的 8000 端口。

重新生成生产页面：

```bash
npm run build
```

如需让 Django 使用新的构建结果，将生成的 `dist` 替换到 `backend/frontend/dist`。

## 9. 验证命令

```bash
python manage.py check
python manage.py test healthcare
```

本提交版已完成以下验证：

- Django 系统检查通过。
- 后端 56 项测试全部通过。

## 10. 主要源码结构

```text
backend/
├─ healthcare/
│  ├─ models.py          业务数据模型
│  ├─ serializers.py     参数校验与序列化
│  ├─ services.py        预约与号源等业务服务
│  ├─ views.py           REST API
│  ├─ permissions.py     角色权限
│  ├─ tests.py           后端业务测试
│  ├─ migrations/        数据库迁移
│  └─ management/        初始化和流程验证命令
├─ smartmedical/         Django 配置、路由和 WSGI 入口
├─ frontend/dist/        可直接访问的生产前端
└─ manage.py
```
